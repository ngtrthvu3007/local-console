# Cognito User Pools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm service Cognito (chỉ User pools) vào Local Console: pool, user, group, app client, Test sign-in, Lambda trigger, email qua SES, domain + IdP OIDC / Google + hosted UI; nối sang Lambda, SES, SNS.

**Architecture:** Mọi thao tác gọi Floci bằng `@aws-sdk/client-cognito-identity-provider` qua proxy `/aws`, theo mẫu ElastiCache / SNS. Logic thuần nằm riêng để unit test không cần Floci: `auth.ts` (decode JWT, `SECRET_HASH`, URL hosted UI), `poolUpdate.ts` (gộp `Describe*` thành input `Update*`), `triggers.ts` (`LambdaConfig` ↔ dòng bảng, khớp ARN), mapping form → request trong `schemas.ts`. Lambda › Triggers dùng lại `listPoolTriggers` của Cognito. Server không đổi.

**Tech Stack:** React 19, Cloudscape, TanStack Query 5, zod 4 + react-hook-form (`useZodForm`), `@aws-sdk/client-cognito-identity-provider`, WebCrypto, Vite, vitest, Playwright.

**Spec:** [docs/superpowers/specs/2026-11-19-cognito-design.md](../specs/2026-11-19-cognito-design.md). Mã mục (vd "3.4", "7 #14") trỏ tới mục của spec.

## Review Focus

1. **`InitiateAuth` / `RespondToAuthChallenge` gửi không ký** (7 #19): pool ở region khác region mặc định của Floci → `ResourceNotFoundException` cho client có thật. Probe ở Task 7 step 1 (pool ở `us-west-2`), fallback header `Authorization` mang region; IT ở Task 11 step 2 chạy sign-in ở region của console.
2. **Gộp `UpdateUserPool` / `UpdateUserPoolClient`**: gửi trường chỉ đọc của `Describe*` (Id, Arn, CreationDate, ClientSecret…) hoặc gửi cả `AdminCreateUserConfig.UnusedAccountValidityDays` lẫn `TemporaryPasswordValidityDays` → AWS từ chối; quên trường → AWS reset cấu hình IaC. Unit ở Task 3 step 1; IT "sửa trigger giữ `EmailConfiguration`" ở Task 11 step 2.
3. **Pool đăng nhập bằng email**: username là UUID, người dùng gõ email ở Test sign-in; `NEW_PASSWORD_REQUIRED` phải gửi `sub` (7 #7), client có secret tính lại `SECRET_HASH` với `sub`. IT ở Task 11 step 2, E2E ở Task 11 step 3.
4. **Trigger trỏ function đã xóa hoặc ARN có version / alias** (`fn:prod`): mở Edit rồi Save không được âm thầm gỡ trigger đó. Unit `functionOptionArns` ở Task 3 step 1; kiểm tay ở Task 8 step 5.
5. **Xóa pool còn domain** (7 chưa kiểm): phải xóa domain trước, một pool lỗi không chặn pool khác. Probe ở Task 1 step 5; IT ở Task 11 step 2.
