# AppSync — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dev xem / tạo / sửa GraphQL API của AppSync trên Floci (schema, data source, resolver JS / VTL, pipeline function, API key, auth) và chạy thử query bằng API key, Cognito hoặc IAM.

**Architecture:** Service mới `web/src/services/appsync/` theo khuôn CloudFront / KMS (`routes.ts`, `constants.ts`, `schemas.ts`, hàm thuần trong `apis.ts`, hooks TanStack Query, trang `lazyPage`), một dòng trong `registry.ts`. Control plane bằng `@aws-sdk/client-appsync` qua proxy `/aws`; query bằng `fetch` tới `/aws/v1/apis/{id}/graphql` (hàm thuần `graphqlRequest.ts` dựng header theo auth, ký SigV4 cho IAM). Type / field / operation đọc bằng `graphql` (`buildSchema`, `parse`). Không sửa server.

**Tech Stack:** React 19, Cloudscape, react-hook-form + zod (`useZodForm`), TanStack Query v5, `@aws-sdk/client-appsync`, `graphql`, `@smithy/signature-v4`, `@aws-crypto/sha256-js` (mới), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-25-appsync-design.md` (đã duyệt 2026-11-25). Đọc mục 2, 3, 4, 7 trước khi làm.

## Global Constraints

- **Không cài package, không chạy git ghi** (CLAUDE.md). User chạy trước Task 1: `npm install @aws-sdk/client-appsync graphql @smithy/signature-v4 @aws-crypto/sha256-js -w web --min-release-age=7` và `npm install @aws-sdk/client-appsync -w tests --min-release-age=7`. Bước "Commit" = báo file để user tự commit.
- Bốn gói trên chỉ import trong `services/appsync/` (trang tải lười), không ở `shared/` hay `registry.ts`; `index.tsx`, `routes.ts`, `constants.ts` chỉ `import type` từ SDK.
- Route: `/appsync/apis`, `/appsync/apis/create`, `/appsync/apis/:apiId?tab=` (`schema` mặc định không ghi lên URL, `data-sources`, `functions`, `queries`, `settings`), `/appsync/apis/:apiId/resolvers/:type/:field`, `/appsync/apis/:apiId/functions/create`, `/appsync/apis/:apiId/functions/:functionId`. Sidebar nhóm `integration`, mục **APIs**, icon `IconGraph`.
- Giá trị cố định: auth console sửa / gọi được `API_KEY`, `AMAZON_COGNITO_USER_POOLS`, `AWS_IAM`; data source `NONE`, `AMAZON_DYNAMODB`, `AWS_LAMBDA` (không gửi `serviceRoleArn`); runtime JS `{ name: "APPSYNC_JS", runtimeVersion: "1.0.0" }` mặc định, VTL; API key hạn 1–365 ngày, mặc định 7; lưu schema hỏi trạng thái mỗi 1 giây, tối đa 30 giây; tên API tối đa 65 ký tự `[A-Za-z0-9_\- ]`; tên data source / function `[A-Za-z0-9_]`.
- Endpoint hiện cho người dùng: `flociPublicUrl` + path của `uris.GRAPHQL`. Query gửi qua `proxyEndpoint()` + path đó. IAM ký theo host / path của `uris.GRAPHQL` (spec 7 #16).
- Cognito trong Queries gửi `Authorization: Bearer <IdToken>` (spec 7 #10). Subscription không gửi.
- Chữ cố định (tiếng Anh, đúng spec 3): "Deletes the schema, data sources, resolvers, functions and API keys." · "Create an API, or deploy one with CDK, then refresh." · "Floci checks the code only when a query runs: run one in Queries after saving." · "Floci passes arguments to Lambda only through an Invoke request; a resolver without code gets an empty event." · "Floci doesn't support subscriptions." · "Not authorized: check the key or sign in again." · "Save a schema first." · "Floci is still processing the schema. Refresh in a moment." · "The console can't call this API: it uses OpenID Connect or Lambda authorization." · "Edit this authorization with CDK." · "Apps using this key get 401." · "Finish signing in on the user pool page."
- E2E fail khi có `console.error`: luồng E2E không đọc schema của API chưa có schema, không mở resolver chưa có (404).
- Code theo CLAUDE.md: hằng số có tên, comment tiếng Việt ngắn nói lý do, hạn chế type assertion, dòng trống quanh câu lệnh ≥ 3 dòng. Dùng lại `useSubmitOnce`, `ReferenceLink`, `copyable`, `ConnectCard`, `CodeEditor`, `useSignIn`, `useClients`, `useUserPools`, `useTables`, `useFunctions`, `readStorage` / `writeStorage`. Sau khi code: `npm run typecheck`, `npm run lint -w web`, `npx prettier --check`, `/ponytail-review`.

## Review Focus

1. **SDL do CDK / Amplify sinh** (directive `@aws_cognito_user_pools(cognito_groups: [...])`, `@aws_api_key @aws_iam`, scalar `AWSDateTime`, description `"""…"""`, comment `#`, `input`, `enum`, `interface`): `readSchema` vẫn ra type / field → test (Task 1).
2. **API có auth console không sửa** (OIDC, Lambda authorizer, hai Cognito pool): đổi tên hoặc sửa auth không làm mất provider đó → test `withAuthorization` (Task 1).
3. **Query IAM gửi từ trình duyệt qua proxy** (trình duyệt không đặt được header `host`): chữ ký vẫn khớp với host Floci thấy → E2E chạy một query IAM trên UI (Task 9).
4. **Editor Queries có nhiều operation, variables JSON sai, operation là subscription:** chọn operation, báo lỗi variables tại chỗ, không gửi subscription → test `operationsOf`, `parseVariables` (Task 1).
5. **Lỗi lưu schema** (`details` chuỗi JSON có số dòng lệch, hoặc chuỗi lạ không phải JSON): hiện message không số dòng, chuỗi lạ hiện nguyên văn → test `schemaErrors` (Task 1).

**Interfaces:**

- Produces (`constants.ts`): `AUTH_TYPES = { apiKey: "API_KEY", cognito: "AMAZON_COGNITO_USER_POOLS", iam: "AWS_IAM" }` + type `AuthType`; `AUTH_LABELS: Record<string, string>` (3 kiểu trên + `OPENID_CONNECT` "OpenID Connect", `AWS_LAMBDA` "Lambda"); `DATA_SOURCE_TYPES = { none: "NONE", dynamodb: "AMAZON_DYNAMODB", lambda: "AWS_LAMBDA" }` + `DATA_SOURCE_LABELS` ("None", "DynamoDB table", "Lambda function"); `RUNTIMES = { js: "js", vtl: "vtl" }`; `JS_RUNTIME = { name: "APPSYNC_JS", runtimeVersion: "1.0.0" }`; `RESOLVER_KINDS = { unit: "UNIT", pipeline: "PIPELINE" }`; `API_KEY_DAYS = { min: 1, max: 365, default: 7 }`; `SCHEMA_POLL = { intervalMs: 1000, timeoutMs: 30000 }`; `SCHEMA_STATUS = { success: "SUCCESS", failed: "FAILED" }`; `API_NAME_MAX_LENGTH = 65`, `API_NAME_PATTERN`, `RESOURCE_NAME_PATTERN`; `ROOT_TYPES = ["Query", "Mutation", "Subscription"]`.
- Produces (`apis.ts`):
  - `localEndpoint(flociPublicUrl: string, graphqlUri: string): string` (`http://localhost:4566/v1/apis/x/graphql`); `proxyGraphqlUrl(proxyBase: string, graphqlUri: string): string`.
  - `readSchema(sdl: string): { name: string; fields: string[] }[] | null` — `buildSchema(APPSYNC_PRELUDE + sdl)`; object type không bắt đầu `__`, root type đứng trước theo `ROOT_TYPES`; lỗi → `null`.
  - `operationsOf(document: string): { name?: string; kind: "query" | "mutation" | "subscription" }[]` — `parse`; lỗi → `[]`.
  - `parseVariables(text: string): { value?: Record<string, unknown>; error?: string }` — rỗng → `{ value: {} }`; không phải object JSON → error.
  - `schemaErrors(details?: string): string[]` — `JSON.parse` lấy `detail.codeErrors[].value`, bỏ ` [@dòng:cột]` và đoạn vị trí; không parse được → `[details]`.
  - `usageOf(resolvers: Resolver[], functions: FunctionConfiguration[]): { dataSources: Map<string, string[]>; functions: Map<string, string[]> }` — nhãn `"Query.getTodo"` và `"function saveTodo"`.
  - `withAuthorization(api: GraphqlApi, change: { defaultType: AuthType; additional: AuthType[]; userPoolId?: string; region: string }): UpdateGraphqlApiRequest` — giữ provider phụ kiểu `OPENID_CONNECT`, `AWS_LAMBDA` và Cognito pool thứ hai trở đi; giữ `name`, các config đang có.
  - `apiKeyExpires(days: number, nowMs: number): number` (epoch giây).
- Produces (`resolverTemplates.ts`): `STARTER_SCHEMA` (spec mục 4); `templateFor(dataSourceType: string, runtime: "js" | "vtl"): { code?: string; request?: string; response?: string }` cho NONE / DynamoDB `GetItem` theo `id` / Lambda `Invoke` với `payload: { arguments, identity }`.
- Produces (`schemas.ts`): `createApiSchema` `{ name, authType, userPoolId }` (Cognito bắt buộc pool); `dataSourceSchema(existingNames)` `{ name, type, tableName, functionArn, description }`; `resolverSchema` `{ kind, runtime, dataSourceName, functionIds: string[], code, request, response }` (unit cần data source; pipeline ≥ 1 function; JS cần code; VTL cần request); `functionSchema(existingNames)` = các field resolver unit + `name`; `apiKeySchema` `{ description, days }`; `authorizationSchema`; `renameSchema`.
- Produces (`routes.ts`): `APPSYNC_SERVICE_ID = "appsync"`, `APPSYNC_ROUTE_PATTERNS`, `API_TABS = { schema, dataSources: "data-sources", functions, queries, settings }`, `SEARCH_PARAMS = { tab: "tab" }`, `appsyncRoutes = { apis, createApi, api(apiId, tab?), resolver(apiId, type, field), createFunction(apiId), function(apiId, functionId) }`, crumbs.

  const sdl = `"""A todo"""\ntype Todo @aws_cognito_user_pools(cognito_groups: ["admins"]) { id: ID! at: AWSDateTime }\n# comment\ninput TodoInput { title: String }\nenum Status { OPEN }\ntype Query { getTodo(id: ID!): Todo @aws_api_key @aws_iam }\ntype Mutation { addTodo(input: TodoInput): Todo }`;
