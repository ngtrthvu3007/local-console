# Amazon ECS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dev xem / tạo / sửa / xóa cluster, task definition, service; chạy và dừng task Fargate (ghi đè command / env), xem exit code và log; nối ECS với Secrets Manager / SSM, CloudWatch Logs, EventBridge (rule, schedule), Step Functions, CloudFormation trên Floci.

**Architecture:** Service mới `web/src/services/ecs/` theo khuôn EC2 / Kinesis (`routes.ts`, `constants.ts`, `schemas.ts`, hàm thuần trong `arns.ts` + `taskDefinitionJson.ts`, hooks TanStack Query, trang `lazyPage`), một dòng trong `registry.ts`. `ClusterLink` / `TaskDefinitionLink` nằm trong `services/ecs/components/`, chỉ import từ trang tải lười. Mọi thao tác gọi Floci bằng `@aws-sdk/client-ecs` (+ `client-ec2`, `client-cloudwatch-logs` đã có) qua proxy `/aws`; không sửa server.

**Tech Stack:** React 19, Cloudscape, react-hook-form + zod (`useZodForm`), TanStack Query v5, `@aws-sdk/client-ecs`, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-26-ecs-design.md`. Đọc mục 2, 3, 5, 7 trước khi làm.

## Review Focus

1. **`valueFrom` secret có hậu tố JSON key** (`arn:…:secret:db-AbCdEf:password::`) → vẫn link đúng secret `db` → test `secretRefOf` (Task 1).
2. **Command override:** ô trống → không ghi đè; JSON hỏng, không phải mảng, phần tử không phải chuỗi → lỗi form, không gọi API → test `parseCommand` / `runTaskSchema` (Task 1).
3. **Family theo prefix:** revision của `api` không lẫn `api-worker` → test `revisionsOfFamily` (Task 1).
4. **Cluster không có, kể cả `default`:** trang chi tiết hiện "not found", không có `console.error`, và mở `/ecs/clusters/default` không làm Floci tạo cluster → E2E (Task 7).
5. **Task đã mất** (sau restart, hoặc ID gõ tay) → trang task hiện "Task … not found. Floci doesn't keep tasks across restarts.", không `console.error` → E2E (Task 7).

it("links a secret even with a JSON key suffix", () => {
  expect(secretRefOf(SECRET)).toEqual({ kind: "secret", name: "db" });

  expect(clusterNameOf("arn:aws:ecs:r:0:cluster/app")).toBe("app");
