# KMS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dev xem / tạo key và alias, bật / tắt / lên lịch xóa, thử mã hóa / ký / HMAC trên Floci; thấy và chọn key KMS ở 8 service đã có.

**Architecture:** Service mới `web/src/services/kms/` theo khuôn EC2 (`routes.ts`, `constants.ts`, `schemas.ts`, hàm thuần trong `keys.ts`, hooks TanStack Query, trang `lazyPage`), một dòng trong `registry.ts`. Hai component dùng chéo `KeyLink` (dò key, như `QueueLink`) và `FormKeySelect` (ô chọn key trong form react-hook-form) nằm trong `services/kms/components/`, chỉ được import từ trang tải lười. Mọi thao tác gọi Floci bằng `@aws-sdk/client-kms` qua proxy `/aws`; không sửa server.

**Tech Stack:** React 19, Cloudscape, react-hook-form + zod (`useZodForm`), TanStack Query v5, `@aws-sdk/client-kms` (mới), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-25-kms-design.md` (đã duyệt 2026-11-25). Đọc mục 2, 3, 5, 7 trước khi làm.

## Global Constraints

- **Không cài package, không chạy git ghi** (CLAUDE.md). User chạy trước Task 1: `npm install @aws-sdk/client-kms -w web --min-release-age=7` và `npm install @aws-sdk/client-kms -w tests --min-release-age=7`. Bước "Commit" của mỗi task = báo file đã sửa để user tự commit.
- `@aws-sdk/client-kms` không được import ở `shared/` hay `registry.ts` (development.md › Traps: bundle). `index.tsx`, `routes.ts`, `constants.ts`, `keys.ts` của KMS không import SDK runtime (chỉ `import type`).
- Route: `/kms/keys`, `/kms/aws-keys`, `/kms/keys/create`, `/kms/keys/detail?key=<ID | ARN | alias>&tab=`. Sidebar nhóm `security`: **Customer managed keys**, **AWS managed keys**. Icon Tabler `IconKey`.
- Menu thao tác là `ActionBar` (chữ "Actions"); tab Try it theo bố cục tab Test của Lambda; khối code là `CodeSnippet` (copy góc phải).
- Lên lịch xóa 7–30 ngày, mặc định 30 (AWS). Alias: thêm `alias/` nếu thiếu, cấm `alias/aws/`, cấm trùng (Floci nhận trùng). Plaintext Encrypt / message Sign / MAC tối đa 4096 byte (giới hạn AWS).
- Mô tả cố định (tiếng Anh, đúng chữ spec): "Floci doesn't enforce key policies." · "Floci enables the key again; AWS leaves it disabled." · "Secrets, parameters, buckets, queues and other resources keep working with this key on Floci." · "Floci records the key but doesn't stop using it when the key is disabled or deleted." · "Floci doesn't apply the bucket's default encryption to new objects: choose a key when you upload."
- Floci báo key không có bằng `NotFoundException` + HTTP **400** (kiểm 2026-11-25): `isNotFoundError` dùng chung không bắt được, phải dùng `isKeyMissing`.
- Ô chọn key gửi **ARN của key** (`arn:aws:kms:<region>:${FLOCI_ACCOUNT_ID}:key/<id>`), `""` = mặc định của service (không gửi field).
- E2E fail khi có `console.error`: không gây lỗi KMS có chủ đích trong E2E (lỗi key tắt kiểm ở IT).
- Code theo CLAUDE.md: hằng số có tên, comment tiếng Việt ngắn nói lý do, hạn chế type assertion, dòng trống quanh câu lệnh ≥ 3 dòng. Sau khi code: `npm run typecheck`, `npm run lint -w web`, `npx prettier --check`, `/ponytail-review`.
