# SES Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm service SES vào Local Console: hộp thư local (mail app đã gửi qua Floci), identity email, xem/xóa template.

**Architecture:** Identity, template: `@aws-sdk/client-sesv2` qua proxy `/aws`, theo mẫu ElastiCache. Hộp thư: `fetchJson` tới `/aws/_aws/ses` (endpoint riêng của Floci), kiểm bằng zod. Logic thuần (lọc region, sắp, tìm, ghép header, đọc MIME bằng `postal-mime` import động) nằm trong `mailbox.ts`, có unit test; gọi mạng nằm trong hook để `mailbox.ts` test được không cần Floci. HTML của mail và template hiện trong một iframe sandbox dùng chung (`HtmlPreview`). Server không đổi.

**Tech Stack:** React 19, Cloudscape, TanStack Query 5, zod 4 + react-hook-form, `@aws-sdk/client-sesv2`, `postal-mime`, Vite, vitest, Playwright.

**Spec:** [docs/superpowers/specs/2026-11-17-ses-design.md](../specs/2026-11-17-ses-design.md). Mã mục (vd "3.2") trong plan trỏ tới mục của spec.

### Task 2: `mailbox.ts` — đọc hộp thư (logic thuần)

**Files:**

- Create: `ses/mailbox.ts`
- Test: `web/test/services/ses/mailbox.test.ts`

**Interfaces:**

- Consumes: `fromBase64(text: string): Uint8Array` từ `../dynamodb/itemJson.ts` (import chéo service đã có tiền lệ: `dynamodb → lambda`); `UNNAMED_ATTACHMENT` (Task 1).
- Produces:

```ts
export const emailSchema; // field của Floci (spec 7 #14): Id, Region, Timestamp bắt buộc; còn lại .nullish()
export type Email = z.infer<typeof emailSchema>;
export const mailboxSchema = z.object({ messages: z.array(emailSchema) }); // không default: shape lạ là lỗi (spec 5)
export const sentAt = (email: Email): number; // Date.parse(Timestamp)
export function mailboxForRegion(messages: Email[], region: string): Email[];
export function recipientsOf(email: Email): string[]; // To, Cc, Bcc theo thứ tự
export function matchesSearch(email: Email, search: string): boolean;
export interface HeaderLine { name: string; value: string }
export function headersFromFields(email: Email): HeaderLine[];
export interface EmailAttachment { fileName: string; mimeType: string; content: ArrayBuffer }
export interface EmailContent {
  subject?: string; to: string[]; html?: string; text?: string;
  headers: HeaderLine[]; attachments: EmailAttachment[];
}
export async function readEmail(email: Email): Promise<EmailContent>;
export function rawText(rawData: string): string;
```

`emailSchema` (field ngoài 3 field bắt buộc đều `.nullish()`): `Source`, `ReturnPath`, `Subject`, `RawData`, `RejectReason`: string; `Destination: { ToAddresses, CcAddresses, BccAddresses: string[] }`; `ReplyToAddresses: string[]`; `Body: { text_part, html_part: string }`; `Attachments: { FileName: string; ContentType?; Size?: number }[]`; `Headers: { Name: string; Value: string }[]` (đoán theo `MessageHeader` của SES v2, step 1 kiểm).

Quy tắc:

- `mailboxForRegion`: giữ `Region === region`, sắp bản sao theo `sentAt` giảm dần.
- `matchesSearch`: không phân biệt hoa thường, chuỗi con trong `recipientsOf`, `Source`, `Subject`.
- `headersFromFields`: thứ tự From ← `Source`, Return-Path ← `ReturnPath`, To, Cc, Bcc (nối `", "`), Reply-To, Subject, Date ← `new Date(sentAt(email)).toUTCString()`, rồi từng `Headers`; bỏ dòng không có giá trị.
- `readEmail`: có `RawData` → `fromBase64` → `(await import("postal-mime")).default.parse(bytes)` → subject, to (`address` của `to`), html, text, headers (`key`/`value` của postal-mime), attachments (`filename` thiếu → `UNNAMED_ATTACHMENT`; `content` là `ArrayBuffer`, mặc định của postal-mime). Không có `RawData`, hoặc giải base64/đọc MIME ném lỗi → lấy từ field: subject ← `Subject`, to ← `ToAddresses`, html ← `html_part`, text ← `text_part`, headers ← `headersFromFields`, attachments ← `[]` (field chỉ có metadata). Field `null` thành `undefined`.
- `rawText`: `new TextDecoder().decode(fromBase64(rawData))`; base64 sai → trả nguyên `rawData` (spec 5: tab Raw vẫn xem được).

Test và assertion:

- `mailboxForRegion` "keeps this region only, newest first": `[base, { ...base, Id: "b", Timestamp: "2026-11-17T17:16:45.706209Z" }, { ...base, Id: "c", Region: "us-east-1", Timestamp: "2026-11-17T18:00:00.000000Z" }]` → Id `["b", "a"]`.

- `headersFromFields` "builds headers from Floci fields": mail có Source, ReturnPath, To, Cc, ReplyTo, Subject, `Headers: [{ Name: "X-Lc-Probe", Value: "1" }]` → `toEqual` danh sách đúng thứ tự, có `{ name: "Date", value: "Tue, 17 Nov 2026 17:16:45 GMT" }`, không có dòng Bcc.

- `readEmail` "falls back to fields when RawData is broken": `{ ...base, RawData: "%%%", Body: { text_part: "hello text" } }` → không ném lỗi, text `"hello text"`.
- `rawText`: `rawText(btoa(RAW_MIME))` chứa `"Subject: Confirm your account"`; `rawText("%%%")` → `"%%%"`.
- `mailboxSchema` "rejects a response without messages": `mailboxSchema.safeParse({}).success` → `false`.
- `mailboxSchema` "accepts a rejected mail with no content" (spec 7 #17): `{ messages: [{ Id: "r", Region: REGION, Timestamp: base.Timestamp, RejectReason: "Message rejected" }] }` → `success` `true`; `recipientsOf` của mail đó → `[]`.
