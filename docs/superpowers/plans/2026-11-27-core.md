# Tách core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dời logic không dính UI của 25 service (operation gọi SDK / Floci, zod schema, mapper, constants, đường dẫn trang) sang workspace `core/`, web dùng lại, UI không đổi hành vi.

**Architecture:** Workspace `@localconsole/core` (TS chạy thẳng, import tương đối có đuôi `.ts`, không React / DOM). Pattern **Service Facade + DI qua factory function**: operation là hàm thuần `(client, input)`, mỗi service có `create<S>Service(client, deps)` gom operation thành một object; web nối dây theo từng service bằng hook `use<S>Service()` (giữ lazy load SDK), server có root riêng ở plan MCP. Hook của web chỉ còn bọc react-query quanh facade. Làm theo một công thức (mục "Công thức") cho từng service theo thứ tự phụ thuộc, test E2E sau mỗi service, test lại toàn bộ và so bundle ở cuối.

**Tech Stack:** TypeScript 7, npm workspaces, Vitest 5, oxlint 1.93, React 19 + react-query (web), Playwright (tests).

**Spec:** [docs/superpowers/specs/2026-11-27-core-design.md](../specs/2026-11-27-core-design.md)

## Global Constraints

- Không đổi hành vi, giao diện, câu chữ, query key của UI. Chỉ dời code; comment lý do (tiếng Việt) đi theo code.
- `core/` không import `react`, `react-*`, `@cloudscape-design/*`, `@tanstack/*`, `@hookform/*`, kể cả `import type`; không dùng `window`, `document`, `sessionStorage`, `localStorage`, `Buffer`, `process` (oxlint chặn, Task 1).
- Import trong `core/` tương đối, có đuôi `.ts`, không alias. Chỉ cú pháp TS xóa được (`erasableSyntaxOnly`): không `enum`, `namespace`, parameter property.
- Web / server import core qua barrel: `@localconsole/core/shared`, `@localconsole/core/<service>` (vd `@localconsole/core/sqs`). `core/package.json`: `"sideEffects": false`, `exports: { "./shared": "./src/shared/index.ts", "./*": "./src/services/*/index.ts" }`.
- Dependency của core dùng **đúng range** đang có trong `web/package.json` (để npm dedupe, `instanceof` lỗi SDK như `QueueDoesNotExist` vẫn đúng).
- **Không chạy git ghi, không chạy `npm install`.** Bước "báo user" = dừng, nói phần đã sẵn sàng, đưa lệnh / commit message để user tự chạy. Commit message không có dòng attribution.
- Pattern (spec mục 4.1–4.3): facade viết bằng **factory function trả object, không class**; type `type <S>Service = ReturnType<typeof create<S>Service>`; **không Singleton**, không tạo client / facade ở cấp module trong core; **không root gom mọi service ở web** (mỗi service nối dây trong hook của nó); barrel chỉ ở `core/src/shared/index.ts` và `core/src/services/<s>/index.ts` (service barrel không export operation lẻ; trong core import thẳng file); operation không import operation / facade của service khác để gọi, nối service đi qua `deps`; không vòng import giữa các service.
- Bundle: chunk `index` và lần tải đầu không tăng quá 5% so với mốc Task 1; không SDK client nào vào lần tải đầu.
- Không hardcode: hằng mới đặt tên theo ý nghĩa trong `constants.ts`.
- Quy tắc trong `CLAUDE.md` (comment tiếng Việt giải thích lý do, dòng trống quanh khối ≥ 3 dòng, `/ponytail-review` sau khi viết) áp cho mọi task.

## Công thức tách một service (R1–R7)

Áp cho mọi task service. Task ghi thêm chỗ riêng của service đó.

- **R1 — File thuần.** Dời mọi `web/src/services/<s>/*.ts` **trừ** `codeSamples.ts` và `routes.ts` sang `core/src/services/<s>/`, giữ tên file. Sửa import: `@shared/x.ts` → `../../shared/x.ts`; file service khác → `../<khác>/x.ts`. Phần dính UI trong các file này (`StatusIndicatorProps`, type lấy từ component) **ở lại web**: để trong `web/src/services/<s>/constants.ts` (web giữ file này cho phần UI; core có `constants.ts` riêng cho phần còn lại). Type đang khai báo trong hook mà file thuần dùng: dời sang file operation sinh ra nó (R3).
- **R2 — Đường dẫn.** Từ `routes.ts`: `<S>_SERVICE_ID`, `*_ROUTE_PATTERNS`, các hằng tab / search param, object `<s>Routes` → `core/src/services/<s>/paths.ts`, thay `generatePath` bằng `fillPath`, `withTab` / `withQuery` lấy từ `core/src/shared/paths.ts`. `web/.../routes.ts` giữ crumbs (và thứ dính react-router) và re-export các tên trên từ core để file khác của web không phải đổi import.
- **R3 — Operation.** Mỗi `hooks/useX.ts` có `queryFn` / `mutationFn` → `core/src/services/<s>/operations/x.ts` (`x` = tên hook bỏ `use`, chữ đầu thường; vd `useQueues.ts` → `operations/queues.ts`). Mỗi thân `queryFn` / `mutationFn` thành một hàm export:
  - Tên: query số nhiều `list<Resource>s`, query một `get<Resource>`, mutation = tên hook bỏ `use` (`useCreateQueue` → `createQueue`, `useDeleteQueues` → `deleteQueues`).
  - Tham số đầu: client SDK của chính service (`sqs: SQSClient`). Gọi endpoint riêng của Floci / API của console: `baseUrl: string`. Không nhận client của service khác: phần nối service làm ở facade qua `deps`.
  - Đã có hàm thuần cùng việc (vd `queueExistsQuery`, `describeQueue`, `createCluster` của docdb): dời nguyên, giữ tên.
  - Thân hàm dời **nguyên văn** (kể cả chỗ né bug Floci, comment). Không gọi `notify…`; trả `{ count, failures }` của `runEach` như cũ để hook notify.
- **R3b — Facade.** `core/src/services/<s>/service.ts`: `export function create<S>Service(client, deps) { return { <tên operation>: (…) => <operation>(client, …), … } }` và `export type <S>Service = ReturnType<typeof create<S>Service>`.
  - Method = mọi operation của service, cùng tên. `deps` chỉ gồm facade service khác (`lambda: LambdaService`) và `flociUrl` / `consoleApiUrl` khi cần.
  - Nhiều client của cùng service (EventBridge + Scheduler, API Gateway REST + v2): tham số đầu là object `{ events, scheduler }`.
- **R3c — Hook nối dây (web).** `web/src/services/<s>/hooks/use<S>Service.ts`: `useMemo(() => create<S>Service(client, { lambda }), [client, lambda])` với `lambda = useLambdaService()`. Hook cũ trả client (`useSQS`) giữ cho nơi còn cần client. Mọi hook dữ liệu: `const sqs = useSqsService()`, giữ `queryKey`, `retry`, `refetchInterval`, `onSuccess` / invalidate, notify; `queryFn: sqs.listQueues` hoặc `() => sqs.getQueue(name)`. Trang service khác đang gọi hàm thuần với client (vd `queueExistsQuery(client, name)`): giữ nếu là query option dùng chung, đổi sang facade nếu là lệnh gọi.
- **R4 — Component gọi SDK trực tiếp** (task ghi rõ file): chuyển lệnh gọi vào operation, component gọi qua hook.
- **R5 — Test.** `web/test/services/<s>/*.test.ts` test file đã dời → dời sang `core/test/services/<s>/`, sửa import; test import từ `hooks/` → import từ `operations/`. Test của component / hook (nếu có) ở lại web. Không thêm test mới cho code chỉ dời chỗ.
- **R6 — Kiểm tĩnh.** `npm run typecheck`, `npm run lint`, `npm test` ở root: PASS. `grep -rn "services/<s>/" web/src | grep -v "web/src/services/<s>/"` chỉ còn import tới `components/`, `pages/`, `hooks/`, `routes.ts`, `constants.ts`, `codeSamples.ts`, `index.tsx` của web. `npm run build -w web && node tests/bundle/measure.mjs web/dist`: `sdkClientsInInitialLoad` rỗng, `index` trong ngưỡng 5% so với mốc.
- **R7 — E2E.** Chạy dev (`npm run dev:server`, `npm run dev:web`, Floci đang chạy), rồi `cd tests && LOCAL_CONSOLE_URL=http://localhost:5173 npx playwright test --project=e2e e2e/<các spec của service>`: PASS. Báo user commit, message `refactor(core): move <service> logic to core`.
