# Bảo mật Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chặn ba rủi ro do console tự thêm (dev mode lộ ra LAN, bị nhúng iframe, lệnh shell từ tên DocumentDB) và ghi rủi ro được chấp nhận vào tài liệu.

**Architecture:** Địa chỉ bind thành config (`BIND_ADDRESS`, mặc định `127.0.0.1`, image `0.0.0.0`); một middleware đặt `X-Frame-Options: DENY`; trang DocumentDB chỉ in lệnh shell khi tên an toàn. Không thêm package.

**Tech Stack:** Express 5, zod 4, React + Cloudscape, Vitest + supertest.

**Spec:** [docs/superpowers/specs/2026-11-27-security-design.md](../specs/2026-11-27-security-design.md)

**Điều kiện:** làm sau [plan MCP](2026-11-27-mcp-server.md) (thứ tự user chốt 2026-11-27). Nếu plan core đã dời `docdb/clusters.ts` sang `core/src/services/docdb/`, sửa ở đó (Task 3 ghi theo vị trí sau khi tách).

## Global Constraints

- Không thêm đăng nhập, token, HTTPS, rate limit, CSP đầy đủ (spec mục 2 "Không làm").
- `BIND_ADDRESS` mặc định `127.0.0.1`; `Dockerfile` đặt `BIND_ADDRESS=0.0.0.0` (console contract của Floci: "The console MUST bind `0.0.0.0`").
- Header đúng `X-Frame-Options: DENY`, áp cho mọi response.
- Tên an toàn trong shell: `/^[A-Za-z0-9-]+$/` (`SHELL_SAFE_NAME`), không dùng `IDENTIFIER_PATTERN`.
- **Không chạy git ghi, không chạy `npm install`**: dừng, đưa commit message cho user (không có dòng attribution). Quy tắc `CLAUDE.md` (comment tiếng Việt, không hardcode, `/ponytail-review`).

## Review Focus

1. **`npm run dev:web` sau khi server bind `127.0.0.1`** → proxy Vite tới `http://localhost:3701` vẫn chạy dù `localhost` ra `::1` trước. Test: Task 1 bước chạy tay, mở Console Home qua `:5173`.
2. **Floci tự bật console (`FLOCI_SERVICES_UI_IMAGE`)** → image vẫn bind `0.0.0.0`, health Floci thấy console. Test: Task 1 kiểm `docker compose run --rm console printenv BIND_ADDRESS` = `0.0.0.0` và health xanh.
3. **Tên cluster có chữ hoa do app tạo** (`Orders1`) → vẫn hiện lệnh `socat`. Test: Task 3 unit.
4. **Iframe xem trước mail SES** (`srcDoc`) → vẫn hiện sau khi có `DENY`. Test: Task 2 chạy E2E `ses.spec.ts`.
5. **`/mcp` từ máy khác trong LAN khi chạy dev** → không kết nối được. Test: Task 1 chạy tay từ máy / điện thoại khác.
