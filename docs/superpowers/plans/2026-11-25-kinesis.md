# Kinesis Data Streams — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dev xem / tạo / xóa data stream, xem record theo shard (Data viewer), gửi record thử (Put record), và nối stream với Lambda (trigger Kinesis) trên Floci.

**Architecture:** Service mới `web/src/services/kinesis/` theo khuôn EC2 / KMS (`routes.ts`, `constants.ts`, `schemas.ts`, hàm thuần trong `recordData.ts`, hooks TanStack Query, trang `lazyPage`), một dòng trong `registry.ts`. `StreamLink` (dò stream bằng danh sách, dùng `ReferenceLink`) nằm trong `services/kinesis/components/`, chỉ import từ trang tải lười. Mọi thao tác gọi Floci bằng `@aws-sdk/client-kinesis` qua proxy `/aws`; không sửa server.

**Tech Stack:** React 19, Cloudscape, react-hook-form + zod (`useZodForm`), TanStack Query v5, `@aws-sdk/client-kinesis` (đã cài ở `web`), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-19-kinesis-design.md` (đã duyệt 2026-11-19, sửa 2026-11-25). Đọc mục 2, 3, 5, 7 trước khi làm.

## Review Focus

1. **Giải mã `Data`:** JSON → một dòng gọn; text UTF-8 (tiếng Việt, emoji) giữ nguyên; byte không phải UTF-8 hợp lệ → "Binary (N bytes)"; rỗng → `""` → test `recordText` (Task 1).
2. **Giới hạn Put record đếm byte UTF-8**, không đếm ký tự; partition key 1–256 → test `putRecordSchema` (Task 1).
3. **Tên stream sai luật bị chặn ở form** (Floci nhận) → test `createStreamSchema` (Task 1).
4. **Data viewer phân trang:** Next records dùng `NextShardIterator`; đổi shard / vị trí thì bỏ iterator cũ; hết record thì khóa Next records → E2E (Task 7).
5. **Stream đã xóa:** link trigger Lambda hiện "(not found)" mà không gọi API trả 400 → E2E không có `console.error` (Task 7).

```ts
const bytes = (text: string) => new TextEncoder().encode(text);

it("shows JSON on one line, text as is, other bytes as binary", () => {
  expect(recordText(bytes('{ "event": "click",\n "page": "/" }'))).toEqual({
    kind: "json",
    text: '{"event":"click","page":"/"}',

    kind: "text",

  });
  expect(recordText(undefined)).toEqual({ kind: "text", text: "" });
```
