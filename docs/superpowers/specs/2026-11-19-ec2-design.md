# EC2 — Thiết kế

> Ngày: 2026-11-19 · Trạng thái: đã duyệt (2026-11-19) · Thuộc: [Local Console](2026-11-09-localconsole-design.md) · [Roadmap](../roadmap.md): đợt 3

## 1. Mục tiêu

Màn hình EC2 với **những tính năng hay dùng** (user chốt 2026-11-19). Floci chạy mỗi instance là một container Docker. Dev local dùng để:

- Xem instance mà CDK hoặc app tạo trên Floci, trạng thái của chúng.
- App gọi EC2 API (start / stop…): thấy trạng thái đổi; hoặc tự bật / tắt instance để test.
- Xem **user data** của instance; launch nhanh một instance kèm user data để thử script.
- Biết instance thuộc stack CloudFormation nào.

**Không làm networking và hibernate** (user chốt 2026-11-19). Mọi thao tác gọi thẳng Floci bằng AWS SDK qua proxy `/aws`. **Server không phải sửa gì.** Đã chạy thử trên Floci 2.4.0 (mục 7).

## 2. Phạm vi

**Nguyên tắc chọn** (user chốt 2026-11-17, bổ sung 2026-11-19): tính năng thỏa (1) dev thường dùng, **hoặc** (2) nối với service khác, **và** (3) Floci hỗ trợ. Chỉ tính năng hay dùng, làm đơn giản, dùng thẳng dữ liệu Floci trả, giống AWS Console.

### Làm trong đợt này

| Nhóm            | Tính năng                                                                 | Tiêu chí        | Floci 2.4.0                                                                     |
| --------------- | ------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------- |
| Instances       | Danh sách: Name, Instance ID, state, type, launch time; lọc theo state    | (1)             | Toàn phần                                                                       |
| Instance state  | Stop, Start, Reboot, Terminate                                            | (1)             | Một phần: Stop ~30 s; Start lại thì process của user data không chạy lại (7 #3) |
| Chi tiết        | Details (ID, state, type, AMI, launch time); User data (giải mã, chỉ đọc) | (1)             | Toàn phần                                                                       |
| Launch instance | Tối giản: Name, AMI, instance type, user data                             | (1) (user chốt) | Toàn phần (user data cần internet, chạy sau 40–80 s, 7 #4)                      |
| StackLink       | "Stack: X" trên trang chi tiết                                            | (2)             | Toàn phần                                                                       |

### Không làm

| Tính năng                                                                               | Lý do                                                                                     |
| --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Networking: security group, VPC / subnet, IP / DNS, Elastic IP, key pair, Connect (SSH) | User chốt 2026-11-19                                                                      |
| Hibernate                                                                               | User chốt 2026-11-19                                                                      |
| Tag (xem / sửa; Name vẫn hiện ở danh sách)                                              | User chốt 2026-11-19                                                                      |

| Output của user data, console output                                                    | Floci không có `GetConsoleOutput`; output chỉ trong log container Floci (phải sửa server) |
| SSM Run Command, snapshot, termination protection, event state-change                   | Floci không hỗ trợ hoặc bỏ qua (7 #6)                                                     |

## 3. Màn hình

Theo quy tắc chung của các service đã làm. Sidebar: **Instances**.

### 3.1 Instances — `/ec2/instances`

```text
Instances (3)                         [↻] [Instance state ▾] [Launch instance]
[🔍 Find instances by name or ID ] [State: All ▾]
 ◯ Name           Instance ID            State          Type        Launch time
 ◯ web-1          i-0a1b2c3d4e5f6a7b8    ● Running      t3.micro    2026-11-19 09:12
 ◯ worker         i-0f9e8d7c6b5a4f3e2    ○ Stopped      t3.small    2026-11-19 08:40
 ◯ —              i-0123456789abcdef0    ✕ Terminated   t3.micro    2026-11-19 08:01
```

- `DescribeInstances` (vòng `NextToken`). Name lấy từ tag `Name` (không có → "—"). Ô tìm lọc theo Name / ID ở client.
- State: `Select` All / Pending / Running / Stopping / Stopped / Terminated. Instance terminated Floci giữ khoảng 1 giờ (giống AWS).
- **Instance state** (chọn một dòng, giống AWS): Stop (Running), Start (Stopped), Reboot (Running), Terminate (khác Terminated). Terminate: `ConfirmModal`. Stop: mô tả "Floci takes about 30 seconds to stop an instance."
- Tự làm mới mỗi `INSTANCE_POLL_INTERVAL_MS` khi có instance Pending / Stopping / Shutting-down.

### 3.2 Chi tiết — `/ec2/instances/:instanceId`

```text
web-1 (i-0a1b2c3d4e5f6a7b8)                        [↻] [Instance state ▾]
● Running · t3.micro                                  Stack: WebStack ↗
[Details] [User data]
```

- **Details:** Instance ID (copy), state, instance type, AMI ID + tên AMI (`DescribeImages`), launch time. `Alert` info ở trạng thái Running sau khi Start lại: "Floci restarts the container only; processes started by user data don't run again." (7 #3).
- **User data:** `DescribeInstanceAttribute` (`userData`) → giải mã base64, hiện bằng `CodeSnippet`. Không có → "No user data". Mô tả: "Floci runs user data about 40–80 seconds after the instance starts. Its output isn't available in the console."
- Tab lưu trên URL (`?tab=`), mặc định Details. Actions giống 3.1.
- Instance không tồn tại: "Instance … not found" kèm link về danh sách.

### 3.3 Launch instance — `/ec2/instances/launch`

```text
Launch an instance
 Name            [web-1                    ]
 AMI             [Amazon Linux 2023 (ami-…) ▾]
 Instance type   [t3.micro ▾]
 User data       ┌ #!/bin/bash                          ┐
                 │ echo hello > /tmp/hello              │
                 └──────────────────────────────────────┘   (optional)
                                              [Cancel] [Launch instance]
```

| Trường        | Ghi chú                                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Name          | Tùy chọn → tag `Name`                                                                                                                       |
| AMI           | `Select` từ `DescribeImages` (catalog của Floci). Mặc định Amazon Linux 2023                                                                |
| Instance type | `Select` từ danh sách cố định trong `constants.ts` (t3.micro, t3.small, t3.medium). Mặc định t3.micro. Floci không đổi tài nguyên theo type |
| User data     | `CodeEditor` (text), tùy chọn; console mã hóa base64 khi gửi                                                                                |

- `RunInstances` (`MinCount: 1`, `MaxCount: 1`, `TagSpecifications` cho Name). Không truyền subnet / security group / key pair → Floci dùng VPC mặc định.
- Launch xong mở chi tiết instance (state Pending → Running ~10 s, lâu hơn khi kéo image lần đầu).
- Mô tả: "User data needs internet access: Floci installs SSH in the container before running it."
- App trong instance kết nối RDS bằng endpoint ở tab Connectivity của RDS (7 #8). Mô tả dưới ô User data: "To reach an RDS database, use its endpoint from the RDS page."

### 3.4 StackLink

- Type `AWS::EC2::Instance`, physical ID = instance ID. Thêm vào `resourceLinks.ts` của CloudFormation → `/ec2/instances/<id>`. Service nào vào `main` sau thì làm phần nối.

## 5. Trạng thái và lỗi

| Tình huống                                 | Hiển thị                                                                                                                                                                                 |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Instance không có                          | "Instance … not found" kèm link về danh sách                                                                                                                                             |
| Launch xong instance thành Terminated ngay | Floci kéo image lỗi hoặc mất network của VPC, không có lý do (7 #5, #9). Chi tiết hiện `Alert` "Floci couldn't start this instance (often an image pull failure). Check the Floci logs." |
| Action không hợp lệ với state              | Khóa nút; lỗi gốc nếu Floci từ chối                                                                                                                                                      |
| Chọn AMI arm64 / Windows / Alpine          | Launch form hiện `Alert` cảnh báo (arm64 trên máy Intel có thể không khởi động; Windows chạy bằng AL2023; Alpine hay bị rate limit). Vẫn cho Launch                                      |
| Catalog AMI tải lỗi                        | `Alert` lỗi kèm nút Retry trên form Launch                                                                                                                                               |
| User data quá 16 KB, tên quá 256 ký tự     | Form chặn theo giới hạn của AWS (user data tính theo byte)                                                                                                                               |
| Bấm Launch hai lần liên tiếp               | Chỉ gửi một lần (ref chặn, vì form kiểm tra bất đồng bộ nên `isPending` bật chậm)                                                                                                        |
| User data không chạy                       | Không thấy được trên console (output chỉ trong log Floci); mô tả ở tab User data                                                                                                         |

## 6. Kỹ thuật

### Package cần cài

User tự chạy (từ thư mục gốc repo):

```bash
npm install @aws-sdk/client-ec2 -w web --min-release-age=7
```

`@aws-sdk/client-ec2` khá lớn: chỉ import trong service EC2 (route của EC2), không import ở `shared/`.

### Cấu trúc thư mục

```bash
web/src/services/ec2/
├── index.tsx, routes.ts, constants.ts      # INSTANCE_TYPES, INSTANCE_POLL_INTERVAL_MS, DEFAULT_AMI_NAME
├── userData.ts                # mã hóa / giải mã base64 (UTF-8)
├── hooks/                     # useEC2 (client), useInstances (list, detail, state actions, launch), useImages
├── pages/                     # InstanceList, InstanceDetail, LaunchInstance
└── components/                # InstanceStateActions, DetailsTab, UserDataTab
```

Một dòng trong `registry.ts`; icon `web/public/icons/ec2.svg`.

### Dùng lại từ phần đã có

| Thành phần                                                                          | Dùng cho               |
| ----------------------------------------------------------------------------------- | ---------------------- |
| `ActionBar`, `refreshAction`, `ConfirmModal`, `CopyButton`, `useZodForm`            | Bảng, actions, form    |
| `CodeEditor`, `CodeSnippet`                                                         | User data (nhập / xem) |
| `StackLink` (CloudFormation)                                                        | Chi tiết instance      |
| `EmptyState`, `emptyOrError`, `NotFound`, `useIsCompact`, `useNotify`, `formatDate` | Trạng thái, thông báo  |

## 7. Rủi ro đã kiểm tra

Chạy thử trên Floci 2.4.0 ngày 2026-11-19, region `ap-southeast-1`. Instance, container và resource tạm đã xóa.

| #   | Rủi ro                                | Kết quả                                                                                                                                                                                                      |
| --- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | **Instance là container**             | **Ổn.** `RunInstances` bật container `floci-aws-ec2-<id>`; Pending → Running ~10 s (AL2023). `DescribeImages` có 31 AMI (Amazon Linux, Ubuntu, Debian, Rocky…); AMI lạ → Amazon Linux 2023                   |
| 2   | **Describe**                          | `DescribeInstances` đủ trường; filter state, tag chạy. `DescribeInstanceAttribute userData` trả base64 đúng                                                                                                  |
| 3   | **Stop / Start / Reboot / Terminate** | Stop ~31 s (container dừng, còn); Start 1 s nhưng **chỉ còn tiến trình chính** — sshd, process user data không chạy lại. Reboot = restart container. Terminate xóa container; instance terminated còn ~1 giờ |
| 4   | **User data**                         | **Chạy**, nhưng Floci cài openssh qua internet trước (AL2023 ~41 s, Ubuntu ~83 s sau Running). Output chỉ trong `docker logs` của container Floci                                                            |
| 5   | **Kéo image lỗi**                     | Instance chuyển thẳng Terminated, không có `stateReason`                                                                                                                                                     |
| 6   | **Không hỗ trợ**                      | `GetConsoleOutput`, `CreateSnapshot` → `UnsupportedOperation`; termination protection bị bỏ qua; SSM `SendCommand` kẹt Pending; không có event state-change sang EventBridge                                 |
| 7   | **CloudFormation**                    | `AWS::EC2::Instance` (cùng VPC, subnet, SG, EIP) tạo thật; tra ngược theo instance ID ra đúng stack; xóa stack terminate instance                                                                            |
| 8   | **App trên EC2 → RDS**                | **Chạy.** Floci gắn container instance vào cả mạng compose: từ trong instance tới endpoint RDS (`172.28.0.2:7001`, `floci:7001`) đăng nhập Postgres và chạy SQL được. Không cần networking trên console      |
| 9   | **Network của VPC mất**               | Docker network của VPC bị xóa khi Floci đang chạy (vd `docker network prune`) → `RunInstances` báo `network … not found`, instance Terminated ngay. Restart Floci thì Floci tạo lại network, launch chạy lại |

**Đã kiểm 2026-11-24** (script Node dùng `@aws-sdk/client-ec2` gọi thẳng Floci): `DescribeImages` (31 AMI), `RunInstances`, `DescribeInstances`, `DescribeInstanceAttribute`, `TerminateInstances` chạy; user data có tiếng Việt đọc lại đúng nguyên văn; `RunInstances` không truyền subnet tự dùng VPC mặc định (`subnet-default-…-a`, `vpc-default-…`). Instance terminated không có `StateReason` hay `StateTransitionReason`, nên không phân biệt được "người dùng terminate" với "Floci khởi động lỗi".

**Đã kiểm qua console** (2026-11-24): SDK trong trình duyệt qua proxy `/aws`; `tests/it/ec2.test.ts` (6 test), `tests/e2e/ec2.spec.ts` (5 test, gồm link hai chiều với stack CloudFormation), `ui/responsive.spec.ts` trên 4 khung (trang danh sách và Launch), chụp tay 1440 / 1024 / 390px: không trang nào cuộn ngang. `DescribeInstances(InstanceIds)` với ID không tồn tại trả 400 và trình duyệt ghi `console.error`, nên trang chi tiết tải cả danh sách rồi tìm theo ID (giống cách CloudFormation tránh lỗi này).

**Chưa kiểm:** kích thước bundle sau khi thêm `@aws-sdk/client-ec2` (build lỗi trên máy Windows do thiếu binding `lightningcss`). `registry.ts` và `resourceLinks.ts` chỉ import `routes.ts` của EC2, SDK chỉ nằm trong các trang tải lười.

**Khác bản thiết kế ban đầu:** icon là glyph Tabler (`IconCpu`) trong `index.tsx`, không có `ec2.svg`; menu của danh sách / chi tiết tên "Actions" (dùng chung `ActionBar`), không phải "Instance state"; `Alert` về Start lại thành dòng trong mô tả tab User data; `Alert` instance Terminated dùng câu trung tính ("If you didn't terminate it, Floci couldn't start it…").

## 8. Thứ tự làm

1. User cài package (mục 6). Icon, khai báo trong `registry.ts`, `useEC2`.
2. Hàm thuần + unit test: `userData.ts` (base64 UTF-8, cả ký tự tiếng Việt).
3. Danh sách, lọc state, Instance state actions.
4. Chi tiết: Details, User data.
5. Launch instance.
6. `StackLink` và dòng trong `resourceLinks.ts` (khi CloudFormation đã vào `main`).
7. Test: integration `tests/it/ec2.test.ts` (launch có user data, stop / start / reboot / terminate, user data đọc lại đúng); E2E một luồng chính; trang danh sách vào `tests/ui/responsive.spec.ts`; instance có tag `Name=lc-it-*` / `lc-e2e-*` vào `tests/it/leftovers.mjs` (terminate).

**Kiểm tra:** chạy trên Floci thật, chụp 1440, 1024 và 390px, không trang nào cuộn ngang. Trọn luồng: Launch instance (Amazon Linux 2023, user data ghi file) → chi tiết Pending → Running → tab User data thấy đúng script → Stop (~30 s) → Start → Reboot → Terminate → instance của stack CDK có "Stack: …".
