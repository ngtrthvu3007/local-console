# S3 — Thiết kế

> Ngày: 2026-11-09 · Trạng thái: chờ duyệt · Thuộc: [Local Console](2026-11-09-localconsole-design.md)

## 1. Mục tiêu

Làm màn hình S3 giống AWS S3 Console, đủ các thao tác dev hay dùng: xem, upload, sửa, xóa bucket và object, tạo pre-signed URL, versioning, và gắn S3 với Lambda để test luồng "upload xong thì xử lý".

Mọi thao tác đều gọi thẳng Floci bằng AWS SDK qua proxy `/aws`. **Server không phải sửa gì.**

Tất cả tính năng trong spec này đã được đối chiếu với [tài liệu S3 của Floci](https://floci.io/floci/services/s3/).

## 2. Phạm vi

### Làm trong đợt này

| Nhóm    | Tính năng                                                                  |
| ------- | -------------------------------------------------------------------------- |
| Bucket  | Liệt kê, tạo, xóa, dọn sạch (empty)                                        |
| Bucket  | Bật/tạm dừng versioning, tag, CORS, bucket policy, event notification      |
| Bucket  | Danh sách multipart upload dở dang + hủy (thêm vào đợt này theo yêu cầu)   |
| Object  | Duyệt theo folder, tạo folder, tìm theo prefix, tải thêm khi danh sách dài |
| Object  | Upload file và folder (kéo thả, nhiều file, có tiến trình), download       |
| Object  | Xóa nhiều, copy, move, đổi tên                                             |
| Object  | Xem trước text/JSON/ảnh, xem và sửa metadata/content-type, tag             |
| Object  | Copy S3 URI / URL, tạo pre-signed URL (GET/PUT)                            |
| Version | Xem các version và delete marker, tải về, khôi phục, xóa hẳn một version   |

### Đợt 2 (trước là "Làm sau")

| Tính năng                             | Ghi chú                                                                       |
| ------------------------------------- | ----------------------------------------------------------------------------- |
| Lifecycle rule                        | 4 hành động Floci thực sự chạy (xem 3.8). Floci quét khoảng 1 phút một lần    |
| Nút "Calculate total size" cho bucket | Ở khối Overview của tab Properties                                            |
| Upload chạy nền khi chuyển trang      | Tiến trình hiện trên thanh thông báo ở mọi trang, giống AWS Console (xem 3.9) |

### Không làm

| Tính năng                                               | Lý do                                                                                                                               |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Replication, khôi phục từ Glacier, chuyển storage class | Floci chỉ lưu cấu hình, không thực hiện                                                                                             |
| Object Lock, SSE-KMS, ACL                               | Ít dùng khi dev; ACL là cơ chế cũ                                                                                                   |
| S3 Select, website hosting                              | Floci hỗ trợ một phần, hiếm dùng                                                                                                    |
| Access point, access log, Requester Pays                | Floci chưa hỗ trợ                                                                                                                   |
| Tải nhiều file thành một file zip                       | Tải từng file là đủ cho dev                                                                                                         |
| Block Public Access                                     | Không cần cho dev. Floci 2.4.0 còn báo sai: bucket chưa cấu hình vẫn trả "bật cả 4", nhưng chỉ thật sự chặn sau khi đã lưu cấu hình |
| Lọc lifecycle theo tag/kích thước, chuyển storage class | Lọc theo prefix là đủ; Floci không chuyển storage class                                                                             |

## 3. Màn hình

### 3.1 Danh sách bucket — `/s3/buckets`

```bash
Buckets (3)                         [↻] [Copy name] [Empty] [Delete] [Create bucket]
[🔍 Find buckets by name          ]
 ○ Name ▲              Created
 ○ my-uploads          2026-11-09 10:12
 ○ app-assets          2026-11-08 17:40
 ○ test-fixtures       2026-11-01 09:03
```

- Chọn **một** bucket thì các nút Copy name, Empty, Delete mới bấm được.
- Bấm vào tên bucket thì mở trang chi tiết.
- Ô tìm lọc ngay trên trình duyệt. Floci không hỗ trợ lọc phía server cho ListBuckets.
- **Chưa có bucket nào:** hiện "No buckets" kèm nút Create bucket ngay trong bảng.

### 3.2 Tạo bucket — `/s3/buckets/create`

| Trường      | Ghi chú                                                                                                                      |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Bucket name | Kiểm tra ngay khi gõ theo luật đặt tên của AWS: 3–63 ký tự, chữ thường, số, `.` và `-`, bắt đầu và kết thúc bằng chữ hoặc số |
| Versioning  | Bật/tắt, mặc định tắt                                                                                                        |
| Tags        | Thêm các cặp key/value, tùy chọn                                                                                             |

Tạo xong thì chuyển sang trang chi tiết bucket và báo "Created bucket my-uploads".

### 3.3 Chi tiết bucket — `/s3/buckets/:bucket`

Tiêu đề là tên bucket. Có 3 tab: **Objects** · **Properties** · **Permissions**.

#### Tab Objects

```bash
my-uploads > images > 2026 >                                   (breadcrumb theo prefix)
Objects (124)   [↻] [Copy S3 URI] [Download] [Actions ▾] [Create folder] [Upload]
[🔍 Find objects by prefix   ]                         [ ] Show versions
 ☐ Name               Type    Last modified       Size
 ☐ 📁 thumbs/          Folder  —                   —
 ☐ avatar.png         png     2026-11-09 10:20    48.2 KB
 ☐ report.json        json    2026-11-09 09:58    1.3 KB
                                                   [Load more]
```

- **Folder:** S3 không có folder thật. Folder được hiểu là prefix kết thúc bằng `/`. "Create folder" tạo một object rỗng có key `prefix/`, giống cách AWS Console làm.
- **Danh sách dài:** mỗi lần tải 1000 mục, có nút "Load more".
- **Menu Actions:** Copy, Move, Rename, Edit metadata, Edit tags, Share with pre-signed URL, Delete.
- **"Show versions"** (chỉ hiện khi bucket bật versioning): bảng liệt kê từng version và delete marker, thêm cột Version ID.

#### Tab Properties

| Khối                | Nội dung                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------- |
| Overview            | Region, ARN (`arn:aws:s3:::my-uploads`), ngày tạo. Dòng **Total size** có nút "Calculate" |
| Versioning          | Trạng thái (Enabled / Suspended / chưa bật), nút Edit                                     |
| Tags                | Bảng key/value, nút Edit                                                                  |
| Event notifications | Danh sách (tên, loại event, prefix/suffix, đích), Create / Delete                         |
| Lifecycle rules     | Danh sách (tên, trạng thái, phạm vi, hành động), Create / Delete (xem 3.8)                |

**Calculate total size:** bấm thì duyệt hết object của bucket, hiện tổng dung lượng và số object, kèm giờ tính. Chỉ đếm bản hiện tại (giống AWS), không đếm version cũ. Nút có trạng thái loading khi đang tính. Kết quả giữ lại khi chuyển tab.

**Tạo event notification:**

| Trường          | Ghi chú                                                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Name            | Tùy chọn                                                                                                                             |
| Event types     | `s3:ObjectCreated:*`, `s3:ObjectRemoved:*` (chọn được nhiều)                                                                         |
| Prefix / Suffix | Tùy chọn, vd: `uploads/` và `.png`                                                                                                   |
| Destination     | Lambda function, SQS queue hoặc SNS topic. Nhập ARN trực tiếp. Lambda có thêm gợi ý chọn function (Autosuggest), vẫn gõ ARN tay được |

#### Tab Permissions

| Khối          | Nội dung                                                                        |
| ------------- | ------------------------------------------------------------------------------- |
| Bucket policy | Editor JSON có kiểm tra cú pháp, Save, Delete                                   |
| CORS          | Editor JSON, có nút "Insert example" chèn sẵn một cấu hình cho phép `localhost` |

### 3.4 Upload — `/s3/buckets/:bucket/upload?prefix=…`

```bash
Upload to my-uploads/images/
┌─────────────────────────────────────────────┐
│   Drag and drop files or folders here       │
│        [Add files]  [Add folder]            │
└─────────────────────────────────────────────┘
Files and folders (3 · 12.4 MB)                          [Remove]
 ☐ avatar.png              images/        48.2 KB
 ☐ video.mp4               images/        12.3 MB
 ☐ notes/readme.md         images/notes/  1.1 KB
                                             [Cancel] [Upload]
```

- Kéo thả được cả folder, giữ nguyên cấu trúc thư mục con.
- Khi upload, mỗi file có thanh tiến trình riêng, cộng thêm tiến trình tổng. Có thể hủy giữa chừng.
- **File lớn tự động chia phần** (multipart, mỗi phần 5 MiB, tải song song 4 phần).
- Content-type tự đoán từ đuôi file.
- Xong thì quay về tab Objects, báo "Uploaded 3 files (12.4 MB)". File nào lỗi thì liệt kê kèm lý do.

### 3.5 Chi tiết object — `/s3/buckets/:bucket/object?key=…`

Có 3 hoặc 4 tab: **Properties** · **Preview** · **Versions** (khi bật versioning) · **Tags**.

| Tab        | Nội dung                                                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Properties | Key, size, content-type, ETag, last modified, S3 URI, object URL (có nút copy), user metadata. Nút "Edit metadata" để sửa content-type và metadata |
| Preview    | Text (tối đa 1 MB, JSON tự format đẹp), ảnh (tối đa 10 MB). File khác hoặc file quá lớn thì hiện "Preview not available" kèm nút Download          |
| Versions   | Danh sách version kèm delete marker. Mỗi dòng: Download, Restore (đưa version này thành bản mới nhất), Delete (xóa vĩnh viễn)                      |
| Tags       | Bảng key/value, Edit                                                                                                                               |

Các nút ở tiêu đề: Download, Copy S3 URI, Share with pre-signed URL, Delete.

### 3.6 Pre-signed URL (modal)

| Trường     | Ghi chú                            |
| ---------- | ---------------------------------- |
| Method     | GET (tải về) hoặc PUT (upload lên) |
| Expires in | 1 phút → 7 ngày, mặc định 1 giờ    |

Kết quả: URL kèm nút Copy. Với PUT thì có thêm một lệnh `curl` mẫu.

URL được ký theo **`FLOCI_PUBLIC_URL`** (`http://localhost:4566`) để mở được từ trình duyệt hoặc app trên máy, không đi qua proxy của console.

### 3.7 Các modal xác nhận

| Thao tác              | Xác nhận                                                                               |
| --------------------- | -------------------------------------------------------------------------------------- |
| Delete bucket         | Gõ lại tên bucket. Bucket còn object thì báo số lượng và đề nghị "Empty and delete"    |
| Empty bucket          | Gõ `permanently delete`. Bucket bật versioning thì xóa cả mọi version và delete marker |
| Delete object(s)      | Liệt kê object sẽ xóa. Bucket bật versioning thì giải thích là chỉ tạo delete marker   |
| Delete version        | Gõ `permanently delete`                                                                |
| Move / Rename folder  | Báo số object sẽ bị copy rồi xóa                                                       |
| Delete lifecycle rule | Liệt kê tên rule sẽ xóa                                                                |

### 3.8 Tạo lifecycle rule (modal)

| Trường                                          | Ghi chú                                                                |
| ----------------------------------------------- | ---------------------------------------------------------------------- |
| Name                                            | Bắt buộc, không trùng rule khác                                        |
| Prefix                                          | Tùy chọn, vd: `tmp/`. Để trống là áp dụng cho cả bucket                |
| Status                                          | Enabled / Disabled, mặc định Enabled                                   |
| Expire current versions after … days            | Hết hạn bản hiện tại. Bucket bật versioning thì chỉ thêm delete marker |
| Delete noncurrent versions after … days         | Xóa vĩnh viễn các version cũ                                           |
| Abort incomplete multipart uploads after … days | Hủy upload dở dang                                                     |
| Delete expired object delete markers            | Ô tick. Không dùng chung với "Expire current versions" (luật của S3)   |

- Ô số ngày để trống là không dùng hành động đó. Phải chọn **ít nhất một** hành động. Số ngày là số nguyên ≥ 1.
- Modal ghi chú: Floci chạy rule khoảng 1 phút một lần, và số ngày được làm tròn lên tới nửa đêm UTC kế tiếp.
- Lưu bằng cách ghi lại toàn bộ cấu hình (S3 không có API sửa từng rule). Xóa hết rule thì gọi `DeleteBucketLifecycle`.

### 3.9 Upload chạy nền

```bash
┌──────────────────────────────────────────────────┐
│ ⟳ Uploading 6 files to s3://demo/       [Cancel] │
│ ████████████░░░░░░  64% · 7.7 of 12.0 MB         │
└──────────────────────────────────────────────────┘
```

- Bấm **Upload** thì việc upload chạy ở nền: có thể rời trang Upload, đi sang bucket khác, việc upload vẫn tiếp tục.
- Mỗi lượt upload có một thông báo "in-progress" ở đầu mọi trang: thanh tiến trình tổng và nút **Cancel**. Không đóng được bằng dấu ✕ khi đang chạy.
- Xong thì thông báo đó đổi thành kết quả: "Uploaded 6 files (12.0 MB)", hoặc cảnh báo kèm danh sách file lỗi. Danh sách object của bucket tự tải lại.
- Nếu vẫn còn ở trang Upload: bảng file vẫn hiện tiến trình từng file như cũ. Xong thì có nút **Done** để về bucket. File lỗi thì bấm **Upload** lần nữa để thử lại những file đó.
- Đóng tab hoặc tải lại trang khi đang upload thì trình duyệt hỏi xác nhận (đóng là mất các file đang upload).
- Chạy được nhiều lượt upload cùng lúc, mỗi lượt một thông báo.

## 4. Cách hoạt động của một số thao tác

| Thao tác             | Cách làm                                                           | Ghi chú                                                                                                    |
| -------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Rename / Move object | `CopyObject` rồi `DeleteObject`                                    | S3 không có lệnh rename                                                                                    |
| Rename / Move folder | Copy và xóa từng object dưới prefix, có tiến trình                 | Có thể lâu nếu folder nhiều file                                                                           |
| Copy                 | `CopyObject`, chọn bucket và prefix đích                           |                                                                                                            |
| Download             | Mở pre-signed GET URL có `response-content-disposition=attachment` | Trình duyệt tải thẳng từ Floci, không phải nạp file vào bộ nhớ. Chọn nhiều file thì tải lần lượt từng file |
| Edit metadata        | `CopyObject` lên chính nó với `MetadataDirective=REPLACE`          | Floci chỉ hỗ trợ REPLACE cho user metadata và content-type                                                 |
| Restore version      | `CopyObject` từ version cũ lên key hiện tại                        | Tạo ra một version mới nhất                                                                                |
| Empty bucket         | `ListObjectVersions` rồi `DeleteObjects`, mỗi lần 1000 mục         |                                                                                                            |
| Upload               | `Upload` của `@aws-sdk/lib-storage`                                | Tự chia phần, báo tiến trình, hủy được                                                                     |
| Calculate total size | `ListObjectsV2` lần lượt từng trang (1000 object) rồi cộng `Size`  | Bucket rất lớn thì tính lâu, nút loading suốt lúc đó                                                       |
| Lifecycle            | `Get/PutBucketLifecycleConfiguration`, `DeleteBucketLifecycle`     | Floci không kiểm tra cấu hình khi lưu; UI tự validate trước                                                |

## 5. Trạng thái và lỗi

| Tình huống                                    | Hiển thị                                                                           |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| Đang tải                                      | Bảng giữ nguyên khung và hiện "Loading…" (trạng thái loading của Cloudscape Table) |
| Không có bucket / folder trống                | Một câu trong khung bảng, kèm nút hành động chính (Create bucket / Upload)         |
| Lỗi từ S3 (vd: `BucketNotEmpty`, `NoSuchKey`) | Flashbar đầu trang với mã lỗi và message gốc                                       |
| Bucket hoặc object không tồn tại              | Trang báo "Bucket my-uploads not found" kèm link về danh sách                      |
| Thao tác hàng loạt lỗi một phần               | Báo số thành công và số lỗi, liệt kê các mục lỗi kèm lý do                         |
| Floci tắt                                     | Banner chung của app đã có sẵn, bảng hiện lỗi kèm nút Retry                        |

Sau mỗi thao tác thành công: hiện Flashbar "success" ngắn, rồi tự tải lại danh sách liên quan.

## 6. Kỹ thuật

### Package cần cài

| Package                         | Để làm gì                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| `@aws-sdk/client-s3`            | Gọi S3                                                                                     |
| `@aws-sdk/s3-request-presigner` | Tạo pre-signed URL                                                                         |
| `@aws-sdk/lib-storage`          | Upload có chia phần và tiến trình                                                          |
| `ace-builds`                    | Editor JSON có tô màu cú pháp (Cloudscape `CodeEditor` cần package này) cho policy và CORS |

### Cấu trúc thư mục

```bash
web/src/services/s3/
├── index.ts                 # khai báo service (id, name, routes) để thêm vào registry
├── client.ts                # S3Client qua /aws và S3Client ký theo FLOCI_PUBLIC_URL (cho pre-signed)
├── hooks/                   # useBuckets, useObjects, useObjectVersions, useUpload, useBucketPolicy…
├── pages/                   # BucketList, CreateBucket, BucketDetail, Upload, ObjectDetail
└── components/              # ObjectsTable, PresignModal, DeleteModals, TagEditor, CodeEditor…
```

- **Mỗi thao tác là một hook** dùng TanStack Query: `useQuery` để đọc, `useMutation` để ghi, tự tải lại dữ liệu sau khi ghi.
- `TagEditor` và `CodeEditor` (trước tên là `JsonEditor`, nay có thêm prop `language`) đặt ở `web/src/shared/components/` vì Lambda và DynamoDB cũng sẽ dùng.
- Thêm S3 vào `registry.ts` thì S3 tự xuất hiện ở menu trái và trên trang Home.
- **Server không đổi.**

### Hai S3Client

| Client | Endpoint           | Dùng cho                                    |
| ------ | ------------------ | ------------------------------------------- |
| Thường | `<origin>/aws`     | Mọi thao tác API                            |
| Ký URL | `FLOCI_PUBLIC_URL` | Chỉ để tạo pre-signed URL (cả URL download) |

Cả hai dùng `forcePathStyle: true`, credential `test/test`, region lấy từ `/api/config`.

## 7. Rủi ro cần kiểm tra trước

| #   | Rủi ro                                                                                                                                 | Nếu xảy ra thì                                                                                                         |
| --- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 1   | **Pre-signed URL ký theo `localhost:4566`** có được Floci chấp nhận không (rủi ro 2 của spec chính)                                    | **Đã kiểm tra: ổn.** GET và PUT (bằng curl) đều 200. Floci mặc định không kiểm tra chữ ký                              |
| 2   | **Upload từ trình duyệt qua proxy:** `PutObject`/`UploadPart` gửi body lớn qua `http-proxy-middleware`                                 | **Đã kiểm tra: ổn.** 40 MB qua CLI, 12 MB qua trình duyệt (3 phần, ETag `…-3`)                                         |
| 3   | **Event notification tới Lambda:** trên AWS phải có `lambda:AddPermission` thì S3 mới gọi được Lambda. Chưa rõ Floci có bắt buộc không | **Đã kiểm tra:** Floci không cần `AddPermission`, nhưng **đích phải tồn tại** (không thì `InvalidArgument`), giống AWS |
| 4   | **Kéo thả folder:** dùng `webkitGetAsEntry` / `webkitdirectory`. Chrome, Edge, Firefox, Safari đều hỗ trợ nhưng cần thử                | Không kéo được thì vẫn còn nút "Add folder"                                                                            |
| 5   | **Thanh tiến trình** khi upload qua proxy có chính xác không                                                                           | Chấp nhận tiến trình theo từng phần 5 MiB                                                                              |

## 8. Thứ tự làm

1. Kiểm tra rủi ro 1, 2, 3.
2. Cài package, thêm `client.ts` và khai báo S3 trong `registry.ts`.
3. Danh sách bucket, tạo bucket, xóa/dọn bucket.
4. Tab Objects: duyệt folder, tạo folder, tải thêm, xóa.
5. Upload (file, folder, kéo thả, tiến trình).
6. Chi tiết object: properties, preview, download, sửa metadata, tag.
7. Copy, move, rename, pre-signed URL.
8. Versioning: bật/tắt, xem version, khôi phục, xóa version.
9. Tab Permissions: bucket policy, CORS.
10. Event notification.
11. Thêm số bucket vào trang Home.

**Kiểm tra mỗi bước:** chạy trên Floci thật và chụp màn hình ở 3 độ rộng (theo yêu cầu hiện tại thì chưa viết test).

## 9. Quyết định

| Quyết định                                                                              | Lý do                                                                                                                  |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Làm 1, 2, 4, 5, 7 của danh sách đề xuất (notification, policy, tag, metadata, copy URI) | Dễ làm mà hay dùng khi dev                                                                                             |
| Download bằng pre-signed URL thay vì `GetObject` trong trình duyệt                      | Không nạp cả file vào bộ nhớ, file lớn vẫn tải được                                                                    |
| Destination của notification nhập bằng ARN                                              | SQS/SNS chưa có trong console. Lambda đã có gợi ý chọn function                                                        |
| Không làm zip khi tải nhiều file                                                        | Phải thêm thư viện, mà dev ít cần                                                                                      |
